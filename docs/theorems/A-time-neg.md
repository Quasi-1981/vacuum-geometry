## FUNCTION

Time is not a subset of order: the Weyl channel (sgn/w₀) yields only an arrow (identified with T28, w₀), not an axis, even though sgn itself is well-defined.

> **Boundary:** Negative dimension: time is not derived from order; only the arrow survives, linked through T28.
